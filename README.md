# ChatGPT Plus 包含 Codex 吗：套餐权益、使用额度与第三方订阅渠道说明

**包含。** 截至 2026 年 10 月 1 日，ChatGPT Plus 已包含 Codex 使用权限。OpenAI 官方说明显示，Plus 用户可以使用 Codex，但具体可用额度、重置周期和功能范围会受到套餐、账户状态、任务复杂度以及 OpenAI 当前政策的影响。它不是一个需要另外购买的独立会员。

不过，“包含 Codex”不等于无限使用，也不等于包含 OpenAI API 余额。很多人第一次订阅时把这几件事混在一起，结果不是发现 Codex 有额度限制，就是把 ChatGPT Plus 当成 API 套餐使用。下面把 ChatGPT Plus、Codex、API 以及通过 WildAI（bewild.ai）订阅时需要注意的事项拆开说明。

## ChatGPT Plus 到底包含哪些 Codex 权益？

Codex 是 OpenAI 面向软件开发任务推出的 AI 编程智能体，可以协助编写、修改、审查和发布代码。根据官方帮助中心，Codex 可以通过网页、桌面应用、CLI 和 IDE 扩展等方式使用，登录时使用的是 ChatGPT 账户。

ChatGPT Plus 通常可以使用以下类型的 Codex 能力：

- 根据自然语言需求生成代码
- 阅读和解释现有项目
- 修改文件或补充功能
- 检查代码问题
- 编写测试
- 协助调试
- 在符合条件的环境中运行开发任务
- 通过 Codex 网页版、桌面端、命令行或 IDE 扩展使用

但可用权限不是“买了 Plus 就拥有一台无限算力的远程程序员”。Codex 会根据你的套餐提供相应额度。OpenAI 当前价格页将免费版标记为有限 Codex 使用，而 Plus 提供更高的 Codex 使用量。

简单理解：

> ChatGPT Plus 包含 Codex 的入口和使用额度，但额度有边界，且不同任务消耗速度不同。

短小的代码修改通常比长时间运行、需要大量上下文或多轮工具调用的任务消耗更少。官方帮助中心也说明，共享配额方案下，Codex、ChatGPT Work 以及部分相关功能可能使用同一个额度池；任务复杂度、上下文长度、模型和运行方式都会影响实际用量。

## ChatGPT Plus 与 Codex 是什么关系？

可以把两者理解成“订阅套餐”和“套餐内的工具”。

| 项目 | ChatGPT Plus | Codex |
| --- | --- | --- |
| 定位 | ChatGPT 的订阅套餐 | 面向编程和软件开发的 AI 智能体 |
| 是否需要单独购买会员 | 不需要 | 通常通过符合条件的 ChatGPT 套餐使用 |
| Plus 是否包含 | 是 | 是，但受使用额度限制 |
| 主要用途 | 对话、文件分析、研究、图像、推理等 | 写代码、改代码、运行任务、代码审查 |
| 是否等于 API | 不是 | 也不是 |
| 是否无限使用 | 不是 | 不是 |
| 登录方式 | ChatGPT 账户 | 可使用 ChatGPT 账户登录 |

OpenAI 官方目前将 Codex 作为多个 ChatGPT 套餐中的功能提供，Plus、Pro、Business、Edu 和 Enterprise 等套餐都可能包含相应权限；不同套餐的使用量并不相同。

因此，如果你的问题只是“我订了 ChatGPT Plus，能不能使用 Codex”，答案是：**可以，前提是登录的是同一个具备 Plus 权益的 ChatGPT 账户，并且所在地区、客户端和账户状态符合当前开放条件。**

## ChatGPT Plus 里的 Codex 是无限的吗？

不是。

Codex 的额度可能按照时间窗口重置，例如五小时周期、每周周期或账户页面显示的其他周期。实际限制可能随着 OpenAI 的产品调整而变化，不能只根据某篇旧教程中的数字判断当前额度。

影响使用量的因素包括：

- 使用的模型
- 任务复杂度
- 输入代码和项目文件的数量
- 上下文长度
- 是否要求较高推理强度
- 是否需要运行命令或测试
- 是否连续进行多轮修改
- 任务是在本地、网页还是云端运行

例如，以下任务的消耗通常不会处于同一个水平：

1. 让 Codex 修改一个按钮颜色。
2. 让 Codex 阅读一个大型项目并定位登录问题。
3. 让 Codex 修改多个文件、运行测试、根据错误继续修复。
4. 让 Codex 持续处理一个复杂项目并反复执行命令。

所以，Plus 更适合个人开发者、学习编程、处理小型项目或进行阶段性的代码协助。如果你每天都要让 Codex 长时间运行多个大型仓库，Plus 的额度可能很快成为限制，需要查看账户中显示的可用量，或者评估更高档位及额外额度方案。

## ChatGPT Plus 包含 OpenAI API 吗？

不包含。

这是最容易被误解的一点。ChatGPT Plus 是 ChatGPT 产品的订阅，OpenAI API 则是开发者平台的独立计费项目。官方 Plus 帮助页面明确说明，API 使用需要单独计费，不会因为你购买了 Plus 就自动获得 API 余额。

也就是说：

- 你可以用 Plus 登录 ChatGPT。
- 你可以在符合条件的情况下使用 Codex。
- 你可以使用 ChatGPT 网页和支持的客户端功能。
- 但你不能因为有 Plus，就直接获得 API 余额。
- 在代码里调用 OpenAI API，仍需要单独配置 API 账户和计费方式。

Codex 使用 ChatGPT 登录通道时，消耗的是 ChatGPT 套餐对应的使用额度；如果你使用自己的 API Key，则按照 API 的计费方式处理。不要把 `API Key`、ChatGPT 登录和 Codex 登录混成一个概念。WildAI 的帮助文档也特别提醒，ChatGPT Plus 和 OpenAI API 是两个独立的计费项目。

## 通过 WildAI 订阅 ChatGPT Plus，能不能使用 Codex？

从产品逻辑上看，如果 WildAI 成功为你的 ChatGPT 账户开通的是官方账户里的 ChatGPT Plus 权益，那么 Codex 是否可用，主要取决于这个 ChatGPT 账户在 OpenAI 侧显示的实际套餐和功能权限。

WildAI 的公开页面提供 ChatGPT Plus、ChatGPT Pro 以及其他 AI 服务订阅入口。其帮助文档也提到 ChatGPT Plus、Pro 和 Codex 的使用问题，并说明 Codex 应使用 GPT 账号登录，而不是通过第三方 API 中转地址使用。

但需要把两件事分开：

- WildAI 是第三方订阅服务，不是 OpenAI 官方订阅页面。
- 购买成功不等于所有 Codex 功能都一定立即可用。
- 最终能否使用，仍要以 ChatGPT 账户实际显示的套餐和 Codex 页面状态为准。
- 如果账户处于验证、升级处理中或官方侧额度异常，Codex 可能暂时无法使用。
- 如果你在 Codex 中配置了第三方 API Base URL，可能会出现 401、402、403 或权限范围错误。

## 下单前要注意账号凭证问题

WildAI 的 ChatGPT 订阅教程要求用户登录自己的 ChatGPT 账号，然后在浏览器中获取 session 信息提交给平台，以便完成订阅开通。Pro 5x 教程还提到可能需要提交 Cookie 信息。

这类操作涉及敏感登录凭证，风险不能忽略。session 或 Cookie 一旦泄露，可能影响 ChatGPT 账户安全。因此下单前至少应确认：

- 使用的是自己的 ChatGPT 账号。
- 不要把 session、Cookie 或完整登录信息发给任何个人。
- 只在平台明确的订单流程中提交。
- 不要把凭证复制到聊天群、论坛或不明网页。
- 完成订阅后检查账户邮箱、套餐状态和登录设备。
- 如果平台要求使用浏览器插件，先确认插件来源和权限。
- 不要在第三方 API 页面输入 ChatGPT 密码或 API Key。
- 订阅失败时不要连续重复付款。

WildAI 的帮助文档也提醒，凭证仅用于本次开通，应当妥善保管；如果订单还在处理中，不建议重复支付。

## Codex 无法使用时怎么排查？

如果你已经有 ChatGPT Plus，但 Codex 仍然打不开，可以按下面的顺序检查。

### 1. 确认登录账号

先确认 ChatGPT 和 Codex 是否登录了同一个账号。很多人浏览器里登录了一个邮箱，桌面端或 CLI 却使用了另一个邮箱，最后看到的套餐自然不同。

### 2. 查看 ChatGPT 套餐状态

进入账户设置，确认页面显示的确实是 Plus，而不是 Free 或正在升级中的状态。如果刚完成订阅，平台或官方侧可能需要等待一段时间同步。

### 3. 检查 Codex 使用额度

如果 Codex 可以打开但任务无法运行，查看用量页面是否已经达到当前周期限制。额度耗尽和订阅失效是两种不同的问题，处理方式也不一样。

### 4. 不要使用错误的 API 通道

如果 Codex 报错中出现 `401`、`402`、`403`、`Missing scopes` 或“无权访问 Codex 专用分组”等信息，检查是否误用了第三方 API Base URL、API Key 或中转服务。WildAI 的帮助文档建议切回官方 ChatGPT 登录方式。

### 5. 检查客户端版本

Codex 的网页、桌面端、CLI 和 IDE 扩展可能有不同的功能开放情况。官方帮助中心建议使用对应客户端提供的登录流程，并根据页面提示完成设置。

### 6. 区分官方故障与账户问题

如果 ChatGPT 网页、Codex 页面和账户套餐都显示正常，但额度突然异常、功能不一致或任务批量失败，可能是官方侧服务或额度系统的问题。这种情况下重复订阅通常解决不了问题。

## Plus、Pro 还是单独购买 Codex 额度？

可以按使用强度做判断。

**选择 Plus：**

- 每周只写几次代码。
- 主要是修改小功能、解释报错和生成测试。
- 需要 ChatGPT 的研究、文件分析和普通对话功能。
- 不希望为暂时用不到的高额度付费。

**考虑 Pro 5x：**

- 经常处理代码任务。
- 项目规模比简单脚本更大。
- 需要进行多轮调试。
- Plus 的 Codex 额度经常不够用。

**考虑 Pro 20x：**

- 同时维护多个项目。
- 经常让 Codex 执行长任务。
- 需要更高频率使用编程工具。
- 能够接受更高订阅成本，并且确实会用到额外额度。

如果只是为了“偶尔试一下 Codex”，直接购买高档位通常没有必要。先确认 Plus 能否满足你的任务量，再根据实际用量决定是否升级，判断会更可靠。

## 最终结论

ChatGPT Plus **包含 Codex**，但包含的是受套餐额度限制的 Codex 使用权限，不是无限额度，也不包含 OpenAI API 余额。

如果你通过 WildAI 订阅 ChatGPT Plus，关键在于开通后你的 ChatGPT 账户是否真实显示 Plus，以及 Codex 页面是否能够使用。购买前应核对产品、周期、价格和开通方式；购买后则应检查套餐状态、Codex 额度和登录账号是否一致。

对于大多数个人用户，Plus 已经足够处理日常代码生成、调试、代码解释和小型项目任务。真正需要更高档位的，通常是每天长时间使用 Codex、同时处理多个代码库，或者频繁运行复杂开发任务的人。
